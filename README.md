# Flash Training v2

面向大学生的短时职业任务练习：课程→知识→可观察的行动原子→岗位任务。初始内容包含3个岗位、9个知识概念、15个行动原子、6个约5分钟的文字任务。这是人工编写的教学起步示例，未经行业或学习效果验证。

## 从学过到会用：迁移训练

`/bridge` 以“核对活动转化简报”为起步案例，提供基线表格、邮件材料变式、可比性边界和综合交付四种固定教学练习。每种练习公开改变的条件与保留的条件，复用原有会话、评分、历史与情境证据。原子定义新增触发线索、适用条件、常见误用和需要澄清的情况，图谱可直接查看。

完成基线后可以关联其会话开始变式，也可以直接尝试各环节。只有案例比较版本一致、原子及评分依据一致、双方完成且三个维度均有无辅助的可观察证据时，才显示分数差异；未关联、缺少证据或使用辅助时解释原因。材料变式可能复用数值，难度未经校准，差异不代表学习的因果效果；同情境变式也不等于跨职业迁移。

提交后的诊断用公式、分母选择、可比性三个短问题检查具体错误假设，保留选择及规则解释，给出课程或原子补练入口。诊断结果单独保存，不直接改写能力得分。综合交付要求按字段提取、核算、可比性判断、结论依次写明依据，首版仍由模型评价文字交付，不自动证明已定位所有错误传播路径。

固定案例出题与诊断使用规则，提交文字交付的评分仍调用已配置模型，可能收费。需求方对话、审阅者返工等工作现场模拟属于后续扩展，本版不提供该交互。

## 本地运行

需要 Python 3.10+、Node.js 22.12+。在 backend/：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.lock
Copy-Item .env.ai.example .env.ai
python -m uvicorn api_server:app --host 127.0.0.1 --port 8001
```

在 backend/.env.ai 填写自己账号可用的 OPENAI_API_KEY、OPENAI_BASE_URL、OPENAI_MODEL。在 frontend/：

```powershell
npm ci
Copy-Item .env.example .env
npm run dev -- --host 127.0.0.1
```

打开 [前端](http://localhost:5173/)；[接口文档](http://127.0.0.1:8001/docs)。未配置模型时可浏览目录和固定案例，普通题生成和文字评分会明确报错。macOS/Linux 使用 source .venv/bin/activate 和 cp。

## 数据与实现边界

新默认库是 backend/data/flash_training_v2.sqlite3，首次初始化从 career_catalog.json 播种，不导入旧技能库与学习历史。旧数据不再是当前产品输入；程序不会自动删除配置指向的数据库。显式设置 FLASH_DATABASE_PATH 时应选择新库。

数据库文件名保留不变，结构升级至 schema v3，在启动事务中为已有 v2 库新增诊断存储，保留会话及历史。目录格式版本仍为 2，内置原子定义版本为 2；启动时只为与原始定义一致、尚无条件字段的 v1 原子补充四类条件，已有自定义改动及历史原子快照不覆盖。

图谱页 /graph 展示课程、知识、行动原子、任务与岗位关联。课程学习不能直接证明行动能力；同一原子可复用于不同场景，电商运营的表现不自动算作产品调研或科研阅读的表现。

四种职责分别是任务设计（模型出题）、原子映射（确定性目录校验）、证据评估（模型加引用校验）、学习规划（确定性推荐）。它们复用应用服务，没有自主联网、执行工具或新增智能体框架。模型适配器在 backend/app/infrastructure/ai.py，提示词和输出校验在 backend/app/application/content.py。

详见 [后端说明](backend/README.md)、[架构说明](backend/架构说明.md)、[数据目录](backend/data/README.md)。

## 最小人工验证

启动后访问 /graph，检查三个岗位及知识、原子、任务关联；选择“核对活动转化简报”，生成题目后提交含算式和材料编号的答案，检查分项证据来自原答案、历史结果可恢复。切换场景后不应沿用原场景表现。

本轮功能最小验证：访问 `/bridge`，完成一次独立基线，关联它开始邮件变式；双方三个原子都有可观察、无辅助证据时应显示配对差值。再做窗口不同的边界题，答案应指出不可直接作同口径比较并提出澄清。提交三题诊断后刷新页面或从历史重新打开，应恢复同一会话、诊断选择及解释；到 `/graph` 点击原子应看到四类条件。使用引导基线的配对应标为含辅助，不报告独立表现分差。

生成和评分会调用配置的真实模型，可能收费；启动、生成和提交会写本地数据库，草稿可能写浏览器存储。密钥和用户数据不提交 Git。当前 user_id 只是数据分组，不是登录认证。
