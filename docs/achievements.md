# 成长成就

成就纪念可核查的学习行为和某次表现，不提供长期掌握认证、排行榜或虚构学习积分。首版 10 项，入口为 `/achievements`，首页、个人中心、侧边栏和顶部均可进入。手机保留顶部入口。

## 达成规则

| 成就 | 规则 |
| --- | --- |
| 心有所向 | 保存一个学习项目，待规划目标也算 |
| 迈出第一步 | 完成一次普通任务或项目非追问轮次的评估 |
| 步履不停 | 完成五个不同任务会话或项目非追问轮次 |
| 换个角度 | 在两个不同任务情境下完成尝试；不表示已迁移成功 |
| 多想一步 | 提交一次项目诊断追问，不要求回答正确 |
| 把思路说清 | 在项目局部练习中提交一次反思 |
| 独立起步 | 完成一次未声明辅助的独立/迁移模式任务，或项目非追问作答；不要求答对 |
| 证据成线 | 三个不同原子具有独立支持证据；普通练习可观察且单项 ≥7/10、有原文引用；项目为 supported、有引用、非追问且无辅助 |
| 新题再试 | 完成项目 verification 轮次，材料不同于此前已作答的任务且未声明辅助；不要求通过 |
| 让理解落地 | 同一项目先出现 gap，再获取帮助，再在新材料 verification 轮次全部目标 supported 且有引用、无辅助；追问后的支持不替代本轮完整证据 |

不按打开页面、点击提示或写草稿颁发任务成就。任务计数按会话/轮次去重；原子计数按 ID 去重，跨情境仍只计同一原子一次。失败的真实尝试也值得纪念，但不提供独立支持证据徽章。

“新材料”当前按项目内已作答任务的材料文本核对，不证明难度相等或用户在外部从未见过。辅助依据系统状态和用户声明，不能检测未声明的外部帮助。原子证据当前沿用 ID 汇总，定义版本和专业准确性等限制与图谱一致。

## 数据与同步

数据库 schema v6 新增 `achievement_awards`，主键为 `(user_id, achievement_id)`。服务端从本人项目快照、会话、原子证据和事件计算规则，前端不上传分数或解锁标志，不调用模型。

`GET /api/v2/achievements` 为只读快照；`POST /api/v2/achievements/sync` 核对进度并持久化新成就；`POST /api/v2/achievements/seen` 接收 `{ids:[...]}` 标记本人通知已读。接口沿用账号 Cookie、请求来源和账号切换校验。

首次进入已登录空间、窗口重新聚焦，以及成功创建项目、提交项目动作或普通练习答案后会触发核对。已有真实历史自动补发：`achieved_at` 为原始达成时间，`awarded_at` 为核对颁发时间。来源保存为可返回原始任务或项目轮次的地址；每项保存规则版本。同步在单次事务内完成，唯一约束避免多标签并发或重试重复颁发，失败自动回滚。

已解锁成就保留，不因后续表现下降或普通记录软删除撤销。当前进度统计使用保留的会话和项目事件，所以删除列表记录不会制造重新刷取机会。用户最新能力状态仍应到图谱查看；未实现撤销或重置成就。通知已读存于数据库，刷新和重新登录不会重复显示已读通知。

成就功能在 v6 引入；当前版本将 v2、两种历史 v3、v4、v5 和 v6 库在一致性备份后增量升级至 v7。保留账号、会话、迁移训练、学习项目及已有成就；数据库文件名不变，schema v1 仍需选择新文件。v7 的个人原子保存在项目定义快照中，其真实作答证据同样参与成就规则；生成或确认拆解草稿不产生能力证据。

## 验证

自动检查使用临时 SQLite 和替代模型，覆盖低分尝试、有辅助与追问排除、闭环时序、新材料校验、按原子/轮次去重、并发同步、账号隔离、已读持久化、软删除、HTTP 认证与 v5 升级及失败回滚。浏览器以隔离账号和数据库验收成就分类、进度、通知、项目学习闭环、原始依据跳转、刷新恢复、账号切换及 390/320 像素布局。上述检查不调用付费模型，不证明模型诊断质量或学习效果。
