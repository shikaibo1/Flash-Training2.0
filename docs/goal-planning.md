# 可审核的个人目标拆解

## 使用流程

在 `/projects` 输入目标、已有基础和希望完成的交付物，可粘贴课程或任务原文。练习范围选择“保存后由教练拆解个人方案”，保存目标后点击“请教练拆解我的目标”。保存目标本身不调用模型；拆解及后续出题、评估使用已配置模型，可能产生费用。

规划聚焦一次文字任务可观察的第一阶段，形成“目标范围 → 1–3 个知识模块 → 2–6 个原子动作”。若缺少关键范围，最多提出两个简短问题，填写补充后重新生成。此前补充会保存并供后续规划参考；每个项目最多成功生成八次方案。这个上限是操作保护，不代表完整课程只能有六个原子。

方案草稿显示任务、情境、范围、交付物和暂不覆盖内容。原子包含动作、输入、输出、边界、评分标准、诊断示例、适用条件、常见误用和前置关系。用户可修改、增删原子和调整已有模块，检查原文，再保存与确认。未保存改动刷新会丢失，页面明确提示；已保存草稿、补充、确认定义和后续学习记录可以恢复。

确认前不创建任务、不颁发能力证据，也不把草案写进公共目录。确认后将定义固定为个人项目快照，状态转为待开始，随后复用已有诊断、提示/解释/局部练习、独立复测、图谱、时间线和成就流程。确认不自动发起第一次出题；用户明确点击开始才调用模型。

原子和任务 ID 按项目分隔，同名原子不自动等同，同名目标可以独立存在。项目图谱使用该方案的知识模块及前置关系；能力证据页的个人原子链接会带上项目范围。原子证据仍使用实际作答，不从方案推断用户已经掌握。其他账号和公共图谱不包含本项目定义。

## 质量与数据检查

- 所有字段、数量、非空标准和关系引用使用类型模型校验；检查重复原子、无效模块、缺失前置、自引用及前置循环。
- 原子依据标为“项目资料原文”时，必须提供在 `source_text` 中逐字连续存在的引用；无直接依据标为“教学补充建议”。引用存在不能证明解释正确或完整，不补造论文页码、链接和权威认证。
- 模型收到的目标、原文、补充和旧方案都作为待分析数据，不作为新的系统指令。未实现外部检索、文件上传或工具执行。
- 生成失败或检查不通过不覆盖原草稿；操作占用会释放，可以重试。生成在数据库事务外执行。
- 项目动作沿用幂等请求标识、版本检查和操作占用；重试相同请求不重复调用模型。过期窗口不能覆盖新版本，页面暂停并要求重新加载。
- 确认使用服务器上已保存方案，不能随确认请求偷换定义。已有定义和学习记录后禁止改方案；改变范围应新建项目。

`GoalPlanner` 负责一次模型提案；`LearningPlan` 和 `check_sources` 负责结构及引用检查；`ProjectService` 负责草案、确认和学习状态，API 仍为原项目 `/actions`，增加 `plan`、`save_plan`、`confirm_plan` 三类动作。`save_plan` 接收 `plan`，`confirm_plan` 不接收方案内容。无需新增 AI 密钥配置。

## 数据库升级

schema v7 新增 `project_atom_snapshots`，以 `(project_id, atomic_skill_id)` 固定定义。`project_observations` 的外键改为引用这份项目定义，避免为了保存个人证据而把私有原子插进公共目录。

升级前一致性备份，支持 v2、两种历史 v3、v4、v5、v6；事务内从既有项目填充定义快照并迁移观察，保留原始观察 ID、时间与 JSON。任何失败回滚结构和版本。已有项目 JSON 没有规划字段时按默认空值读取；旧动作请求指纹保持兼容。原文件名、账号、练习、项目与成就记录保留。schema v1 仍不支持自动升级。

## 验证与尚未实现

新增自动测试覆盖草案持久化、人工修改、引用与图校验、简短澄清、失败恢复、幂等与并发、事务外调用、个人数据隔离、完整学习闭环，以及 v6 观察迁移、备份和失败回滚。浏览器使用临时账号/数据库及替代模型验证实际页面到 API 的完整流程、循环/伪引文提示、双窗口冲突、图谱时间线与成就联动、390/320 像素布局。真实用户学习库不用于自动验收，不调用付费模型。

2026-11-16 完整验证：后端 114 项测试、前端 7 项测试通过，类型检查及生产构建通过，lint 无错误并保留既有 6 条组件导出警告。浏览器验收通过；这些结果验证流程与数据约束，不代表真实模型拆解或诊断准确性已经达标。

本版可以接收不同学科目标并提出首阶段草案，但没有验证对所有学科的专业质量。不实现完整课程递归展开、语义去重与公共原子复用、教师审核、真实模型准确性评测或资料文件解析。文字练习不证明手工实验、编程运行或其他真实现场操作能力。下一步应以人工标注目标及师生试用验证拆分质量、追问必要性与未见题独立表现，再扩展领域与层级。
